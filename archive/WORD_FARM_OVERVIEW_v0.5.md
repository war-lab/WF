# WORD FARM — 概要設計 v0.5

更新日：2026-10-19  
位置づけ：v0.4とレビューを統合した試作基準。実装・実対局・学習効果の検証を完了した最終仕様ではない。

## 1. ゲームの概要

単語を資源として集め、英文で農場を育てる、2〜4人用のブラウザ対戦ボードゲーム。

共有マップの産地に拠点を置き、2D6の出目に応じて単語カードを獲得する。カードを交換し、英文を組み立てて作物の栽培、家畜の購入・給餌、出荷を行う。出荷注文や農場の状態を報告する注文を達成し、12ラウンド終了時の得点を競う。

体験の軸は「作りたい農場 → 使いたい英文 → 必要な単語 → 確保したい産地」。確率・交換・投資の判断と英文の意味をつなげる。長文、文型の難しさ、解答速度そのものに得点を与えない。

| 項目 | 試作基準 |
|---|---|
| 人数 | 2〜4人、ルームコードで参加 |
| 形式 | ターン制、共有の単語マップ＋各自の農場 |
| 終了 | 12ラウンド。全員が12手番を持つ |
| 勝敗 | 得点 → 所持金。それでも同じなら同順位 |
| 想定時間 | 20〜30分を目標。4人・全５文型では超過の可能性あり |
| 対象 | 基礎英語の学習者。難易度はステージで調整 |
| 学習範囲 | 語順、単複、冠詞、動詞の一致、５文型、短い疑問文 |
| 初版に含めないもの | 道路・盗賊・妨害・自由チャット・対戦AI・音声認識・自由英文AI判定・ランキング・課金 |

## 2. 今回の整理と仕様の扱い

v0.5では経済を大きく変更せず、v0.4を試作の基準として維持する。前回レビューの改善案を、検証済みの採用事項に読み替えない。

| 項目 | v0.5の扱い |
|---|---|
| 給餌 | feedカードのみ。食物の支払い不要 |
| SV | 成長＋1、収穫量＋1。収穫加算は1栽培ロットにつき1回 |
| happy | 維持を暫定基準にする。失効案は比較候補として残す |
| 手札上限 | 7枚を暫定基準にする。10枚との比較を残す |
| 銀行SVOO | 標準は本人が1文を組む。渡す側・受け取る側を交換ごとに交互に出す |
| 状況注文 | 7枚・公開1枠を維持。全員に十分なSVC練習を保証するとは扱わない |
| 配布量 | 増やさない。市場の日と救済を維持 |
| 検証結果 | 自ら実行した収入モデルと、提供資料に記載されたルールモデルを区別 |

銀行作文を2文必須から1文へ整理した点は、今回のUI上の設計判断であり、負担軽減や学習効果を実測した結果ではない。2文を作る練習設定は任意で残す。

## 3. コンポーネントと初期状態

各プレイヤーは農場4区画、単語手札、産物倉庫、所持金、得点、産地拠点、非公開の個人目標を持つ。1区画には作物1ロット、または動物1頭を置く。作物のニンジン・ジャガイモは1ロット内に複数あるものとして描画する。

| 項目 | 初期値・上限 |
|---|---|
| 所持金 | 3コイン |
| 農場 | 空き4区画 |
| 初期単語 | grow×2、carrot、potato、sell、buy：計6枚 |
| 拠点 | 初期2個、最大3個 |
| 手札上限 | 自分の手番終了時7枚 |
| 産物倉庫 | 上限なし |
| 通常行動 | 自分の手番に2回 |
| 世話 | ステージDで手番に1回、通常行動を消費しない |

消費カードは動詞grow / buy / feed / sell / makeと、対象名詞carrot / potato / wheat / cow / chicken。makeはDのみ。

I、you、me、the、a、an、数詞、do、have、is、are、give/gives、bank、big、happy、card/cards、andなどの機能語・取引用語は常設。grow/growsなどの語形はカードの選択であり、語尾を別資源にしない。

盤面の動物や倉庫の産物を文中で指す場合、その対象から名詞を使用できる。同名のカードを別途要求しない。「carrotカード」「収穫したニンジン」「big状態」は見た目と配置を分ける。

## 4. 共有マップと2D6

### 4.1 産地

| カテゴリー | 獲得できるカード |
|---|---|
| 栽培 | grow |
| 購入 | buy |
| 飼育 | feed、Dではmakeも選択可 |
| 出荷 | sell |
| 種 | carrot / potato / wheatから1枚 |
| 家畜 | cow / chickenから1枚 |

各カテゴリー2タイル、計12タイル。数字とカテゴリーを分離し、対局開始時に割り当てる。数字トークンは2,3,4,5,6,6,8,8,9,10,11,12。

各カテゴリーに高頻度群5,6,6,8,8,9から1枚、低頻度群2,3,4,10,11,12から1枚を割り当てる。同じ出目のタイルはすべて発動し、そこに拠点を持つ各プレイヤーが拠点ごとに1枚を得る。数字は対局中固定。

| 出目 | それぞれの確率 |
|---|---:|
| 2・12 | 1/36 |
| 3・11 | 2/36 |
| 4・10 | 3/36 |
| 5・9 | 4/36 |
| 6・8 | 5/36 |
| 7 | 6/36 |

公平な独立した6面ダイス2個を使用し、出目の補正は行わない。画面には確率ドットを表示する。

### 4.2 拠点配置

各タイルの枠は人数−1。同じプレイヤーは同一タイルに重複配置不可。初期はランダム席順で高頻度側に1個ずつ、その逆順で低頻度側に1個ずつ置く。同一カテゴリーの高・低に置くことは可能。増設は3コイン＋1行動で、空き枠があるタイルへ配置する。

### 4.3 収入と人数差

各手番開始時に1回振る。ラウンド終了時に4−人数回の追加ロールを行い、通常ラウンドを計4ロールにそろえる。最終ラウンドのみ追加ロールなし。追加ロールで作物の成長や給餌制限は更新しない。

7は市場の日として、全員が任意の単語1枚を得る。通常ロールで手番プレイヤーが無収入なら、任意の単語1枚を補給する。7と救済は重複しない。追加ロールには手番プレイヤーの救済がない。

選択が必要な報酬は権利として保留し、本人の手番開始時に解決する。未解決の権利は交換できない。直接配られるカードは手札に入る。銀行のカード供給は無限。

ラウンドの開始席を1席ずつ回す。総ロール数を調整しても、最終手番までの利用可能収入や交渉相手の数が完全に同じになるわけではない。

## 5. 手番の進行

1. 通常ロール。全員への収入と手番プレイヤーの救済を処理。
2. 自分の作物を自然成長させ、成熟した区画を収穫。給餌制限をリセット。
3. 自分の未解決の選択権をすべて解決。
4. 交渉フェーズ。手番プレイヤーから1件だけ提案できる。
5. 通常行動を最大2回。Dでは別途世話1回を行動の前後・間に挟める。銀行交換も可能。
6. 手札を7枚以下にして終了。全員終了後に追加ロールと注文期限処理。

交渉は標準20秒、行動フェーズは標準60秒。練習設定は制限なし。誤答では資源・行動回数を失わないが、標準の時計は進む。時間切れは未使用行動をパスし、手札超過は古いものから自動破棄する。

## 6. ５文型と行動

文型は行動の意味を理解する補助とする。同じ動詞が複数の文型を取ることを示し、「この動詞は英語全体でこの文型だけ」と教えない。

| 文型・行動 | 英文例 | 費用 | 効果 |
|---|---|---|---|
| SVO・栽培 | I grow carrots. | grow＋carrot、1行動、空き区画 | 成長0で1ロット植える |
| SV・成長 | The carrots grow. | grow、1行動、栽培中の1区画 | 成長＋1。そのロットの収穫に一度だけ＋1 |
| SV・小麦の成長 | The wheat grows. | 同上 | 小麦も同じ処理。語形growsを選ぶ |
| SVO・購入 | I buy a cow. | buy＋cow＋3コイン、1行動 | 牛1頭を配置 |
| SVO・購入 | I buy a chicken. | buy＋chicken＋2コイン、1行動 | ニワトリ1羽を配置 |
| SVO・給餌 | I feed the cow. | feed、1行動 | ミルク2単位。給餌前happyなら＋1 |
| SVO・給餌 | I feed the chicken. | feed、1行動 | 卵2個。給餌前happyなら＋1 |
| SVC・報告 | The cow is happy. | 1行動、対応する注文と状態 | 注文を達成し2点 |
| SVC・報告 | The carrots are big. | 同上 | 注文を達成し2点 |
| SVOC・世話 | I make the cow happy. | make、世話枠 | 選んだ1頭へhappyを付与 |
| SVOC・世話 | I make the carrots big. | make、世話枠 | 選んだ1区画へbigを付与。成長段階は不変 |
| SVO・出荷 | I sell a carrot. | sell＋ニンジン1個、1行動 | 1コイン＋1点、該当注文の追加点 |
| SVO・出荷 | I sell a potato. / I sell wheat. | sell＋該当産物1単位、1行動 | 1コイン＋1点、注文追加点 |
| SVO・出荷 | I sell an egg. | sell＋卵1個、1行動 | 2コイン＋1点、注文追加点 |
| SVO・出荷 | I sell milk. | sell＋ミルク1単位、1行動 | 3コイン＋1点、注文追加点 |
| SVOO・対人交換 | I give you a carrot card. | 提示カード、相手の承諾 | 合意した単語交換を実行 |
| SVOO・銀行交換 | I give the bank three cards. | 単語3枚 | 任意の単語1枚を得る。行動不要 |

ジャガイモ・小麦の栽培もgrow＋対応名詞で行う。給餌に食物を消費せず、小麦は出荷用作物となる。給餌のSVOOは初版の対応範囲から外す。

### 6.1 作物

自然成長は自分の手番開始時に1段階。成長0→1でbigを付与、2で自動収穫して区画を空ける。基本2単位＋bigの1単位で通常3単位。SVによる収穫ボーナスがあれば最大4単位。

SVボーナスは1ロット1回のみ。複数回の成長加速で重複させない。収穫に達するSVでは、ボーナスを付与してから収穫量を計算する。makeで先にbigを付けてもbig自体の加算は重複しない。

成長1の作物をSVで即収穫し、残り1行動で出荷できる。最終手番の栽培→SVは成長1止まりで出荷まで届かない。確定前に見込みを表示する。

### 6.2 動物とhappy

購入直後はhappyなし。1頭につき自分の1手番1回だけ給餌できる。給餌前のhappyを消費して追加生産し、給餌完了で新しいhappyを付与する。基準設定では時間失効しない。

このため通常は初回2単位、その後3単位。makeは初回給餌前の強化、または給餌せずに状態注文を達成する用途となる。この用途が十分かは未解決であり、維持を最良と確定していない。

### 6.3 対象選択

生産・成長・世話は1区画、出荷は1単位。複数形だけで全農場への効果は発生しない。1区画のニンジンは複数なのでthe carrotsを使う。

報告は同種の動物を複数選択でき、全頭が条件を満たせばThe cows are happy.となる。報酬は1注文分のみ。農場に牛が2頭いても、そのうち特定の1頭を選んだThe cow is happy.を正しい文として扱う。

## 7. 注文と得点

| 種類 | 公開枠・総数 | 達成・報酬 |
|---|---|---|
| 出荷注文 | 2枠・13枚 | 対応品の出荷時に基本点へ追加 |
| 状況注文 | 1枠・7枚、B以降 | 事実に合うSVC報告で2点 |
| 個人目標 | 候補2枚から1枚選択、非公開 | 終了時に条件達成で2点 |

出荷注文はcarrot/potato/wheat各3枚で追加1点、egg/milk各2枚で追加2点。初期公開はcarrotとpotato。残りをシャッフルし、達成後すぐ補充。1出荷で達成できる注文は1件。同種の公開注文は許可する。

状況注文はbigのcarrots/potatoes/wheat各1枚、happyのcow/chicken各2枚。公開ラウンドを含む4ラウンド目の終了時に未達成なら捨て札へ送り補充する。両山札とも循環させず、尽きたら補充しない。

状態に固有IDと報告済みフラグを持ち、同じ状態インスタンスは1回しか報告できない。報告しても生産効果は残る。複数頭を報告したら全対象の状態を報告済みにする。既に付いている状態へmakeを重ね、報告回数をリセットすることは不可。

個人目標候補は「3種類出荷」「作物4単位出荷」「動物由来3単位出荷」「状況注文2件達成」（B以降）。未出荷の産物を終了時に自動得点化しない。

## 8. 交換

対人交換は単語カードのみ。手番プレイヤーが相手1人へ、双方1〜2枚の条件を1件提示できる。相手は承諾・拒否。SVOOの文は自分が渡す側を表し、見返りは交換パネルに明示する。

A・BはDo you have a carrot card?、C・DはI give you a carrot card.を標準にする。質問と提示の両方の作文は強制しない。複数種類はandで結ぶ。カード名は引用表示する。

銀行は単語3枚→好きな1枚、行動不要。A・Bはボタン操作、C・Dは交換ごとに次の1文を交互に組む。各プレイヤーの最初の銀行交換は渡す側から始める。

- 渡す側：I give the bank three cards.
- 受け取る側：The bank gives me a sell card.（受取カードに合わせる）

本人が組まない側はシステムが表示する。2文を組む練習設定も選べる。銀行givesの三単現も語形選択として扱う。英文の確定とカード交換を一括で処理し、片側の資源だけが移動しないようにする。

## 9. 学習ステージと文法判定

| ステージ | 内容 |
|---|---|
| A | SVO、短い取引質問。成長・状態は自動効果 |
| B | A＋SV・SVC、成長加速と状況報告 |
| C | B＋SVOO、対人・銀行交換の文 |
| D | C＋SVOC、makeによる世話 |

部屋内は共通ステージ。初回推奨B、全５文型を試す場合はD。文型名と枠の表示は補助として切替可能。

判定は辞書と構文ルールで行い、毎回生成AIを呼ばない。まず語順・単複・冠詞・動詞の一致を検査し、次に対象・所有・状態・費用・ステージ・行動回数を検査する。英文が正しいが実行できない場合と、文法誤りを分ける。

例：The cows is happy.は一致の誤り。選択した牛がhappyでないThe cow is happy.は英文自体は正しく、状態との不一致。I feed a cow.とI feed the cow.は選択対象と文脈に応じて扱い、ゲーム都合で片方を文法誤りにしない。

未対応の正しい表現は「この版では未対応」。Cは形容詞だけとは限らないが、初版の補語語彙はbig/happyに絞る。誤答ではカード・行動回数を減らさず、箇所表示→短い説明→希望時に完成例の順で補助する。

重要な制約：５文型を使える設計であって、対戦1回で全員が各文型を3回以上使うことを保証しない。状況注文7枚では3〜4人全員のSVC3回は不可能。全員の反復学習を必須にする場合は、注文総数や別の個別練習を設計し直す必要がある。これは次段階の検討事項であり、本版で解決済みとはしない。

## 10. 画面とシステム

| 画面 | 主な内容 |
|---|---|
| ロビー | 作成・参加、名前、ステージ、制限時間、準備完了 |
| チュートリアル | 栽培→収穫→出荷、ステージに応じた追加説明 |
| 対戦 | 12産地・確率、自分の農場・倉庫、手札、公開注文、参加者、作文欄 |
| 交換 | 相手、渡す物・受け取る物、英文、承諾・拒否 |
| 結果 | 順位と得点内訳、本人だけの文型図鑑・修正例、再戦 |

ドラッグとタップに対応。動詞または対象から作文を始められる。確定前に英文・対象・費用・効果を一緒に表示する。スマホは農場／マップ／注文を切り替え、作文欄と残り行動を優先する。非手番中も下書き可能だが、実行時に再検証する。

ブラウザは表示と下書き、サーバーが乱数・手番・辞書判定・資源・交換・得点の正を持つ。WebSocket相当の通知、状態保存、再接続を想定。フレームワーク・ホスティング・既存リポジトリへの統合先は未決定。

主なデータは部屋状態、プレイヤー、産地、区画、状態インスタンス、注文、構文辞書、イベント履歴。区画には成長段階、SV加算フラグ、給餌済みを持つ。銀行作文の順番も本人ごとに記録する。

操作には一意のcommandIdと状態revisionを付け、二重実行や古い操作を防ぐ。手札内容・個人目標・下書き・山札順は秘匿。農場・倉庫・所持金・得点・拠点・手札枚数は公開。

切断は1手番1回、最大30秒猶予。その後は未使用行動をパス。未解決の任意補給はgrow、カテゴリー選択は定義順先頭にする。ホスト切断でも継続し、本人トークンで復帰。全員切断で一時停止、24時間後に破棄する案を基準とする。

## 11. 検証の現状

### 11.1 自ら実行した収入モデル

v0.3の収入規則について、2・3・4人を各10,000対局、計30,000対局計算した。固定2拠点、合法ランダム初期配置、拠点追加なし。

| 指標 | 2人 | 3人 | 4人 |
|---|---:|---:|---:|
| 最終手番までの新規収入 | 23.81 | 23.97 | 24.13 |
| 初期6枚込みの累積利用可能量 | 29.81 | 29.97 | 30.13 |

人数差は小さく、理論値とも整合した。ただし語彙・農場・注文・戦略を含まない。実際の行動数・sell不足・勝率・学習効果を示さない。v0.5でも同じ収入規則を採用するが、実対局の拠点増設や交換を含む総供給を上表で保証しない。

1行動1.4枚は仮定であり実測平均ではない。34枚の仮想費用列が平均約21行動にとどまった結果を、実対局で必ず行動不足になる根拠にしない。配布量は据え置く。

### 11.2 提供されたv0.4資料のルールモデル

資料には、給餌をfeedだけに変更すると、固定の作物中心・家畜中心方針の平均点が近づいたと記載されている。採用案の2人戦では約21.5点ずつ、SV使用は作物中心で約1回と報告されている。

一方、再現用として記載されたsimulate_rules.py、experiments.py、exp_v4.pyは本会話では提供されておらず、こちらで追試していない。自ら実行した収入モデルとは別の証拠として扱う。

固定方針・簡易1対1交換・文法ミスと制限時間なしという条件であり、戦略の最適性・実対局の均衡・学習効果の検証ではない。「方針に欠陥はない」「家畜と作物は同じ強さ」とは断定しない。

happy失効の比較は餌費用があったv0.3条件である。feedのみとなった現仕様での比較が必要。SVCとSVOCの合計回数だけでなく、文型別の偏りも評価する。手札7枚も、貯め込み対策として有効だと確定したわけではない。

## 12. 次の比較試作と測定

| 優先 | 比較・測定 | 判断したいこと |
|---|---|---|
| 1 | feedのみでhappy維持／次の自分の手番開始時失効 | 家畜得点とSVOC機会を両立できるか |
| 2 | 動物0・1・2頭を目標とする方針 | 2頭への過剰投資による不利を切り分ける |
| 3 | 現仕様の全５文型：機会・実行・未使用者率 | 実際にSVO以外を使いたくなるか |
| 4 | 手札7／10、銀行作文1／2文 | 破棄・判断時間・入力負担への影響 |
| 5 | 人間同士の交換と注文競争 | 固定方針モデルで見えない駆け引き |

指標の定義をそろえる。

- 文型機会：各通常行動の直前で合法な候補が1つ以上あるか。候補数や同じ状態の繰り返しを無制限に数えない。通常行動外のSVOC・銀行SVOOは別枠で測る。
- 実行数：実際に確定した行動・交換数。銀行で2文表示しても、本人が組んだ文数と交換件数を分ける。
- sell不足：産物と行動枠があるのにsellがない局面を数える。銀行・対人交換で解消できた件数と、解消できず出荷を断念した件数を分ける。
- 方針効率：得点、得点内訳、通常行動使用数、投資したカード・コイン、未出荷在庫、使わなかった動物を併記。収量だけで強弱を決めない。
- 収入：対局終了までの総受取、最終手番までの利用可能受取、交換損、捨て札を分ける。
- 学習：ヒントなしの後日課題で語順や単複を確認。wheatだけでなく未練習の主語でgrow/growsを選ばせ、語彙不足と文法誤りを分ける。

「各文型3回」は学習モードの候補目標に留め、対戦中の強制ノルマにしない。SVC供給とSVOCの使い道が不足した場合、反復を別モードに担わせるか、対戦ルールを変えるかを次に決める。

## 13. 開発の順序と完了条件

1. 1人2役のローカル試作で、ステージDの一対局を最後まで通す。
2. ルールの境界を確認：複数対象、SV加算の順序、状態再報告、注文期限、7と救済の重複、最終ラウンド。
3. 2人オンラインで交換・秘匿情報・二重送信・切断復帰を確認。
4. 3〜4人とモバイルで待ち時間、操作負担、戦略、文型機会を測定。

初回試作の完了条件は、正しい費用・効果・得点で12ラウンドを終了でき、プレイヤーが次に欲しい単語と行動を判断できること。戦略バランスや５文型の学習効果は、その後の評価対象とする。
